# UDJ 학교·교사용 기능 소개영상 스토리보드

- 형식: 학교 담당자에게 시스템을 시연하는 **제품 데모 영상**
- 해상도 1920×1080, 60fps, H.264 High(yuv420p, BT.709), AAC 48kHz, -16 LUFS
- 화면 소재: 실제 UDJ 화면 캡처(Playwright). 기능 장면의 브라우저 창 오른쪽 위 배지로 출처를 표시한다.
  - **"시연용 테스트 환경 · 가상 데이터"** — 실제 UDJ 코드를 테스트 DB로 띄운 로컬 환경(`video/school-demo`), 가상 학교 "예시미래산업고등학교"
  - **"실제 서비스 공개 화면"** — 운영 사이트(udjschool.ggm.kr)의 로그인 없는 공개 화면
- 기능 장면 배치: 왼쪽 = [챕터] [기능명] [한 문장 설명] [사용 방법 단계 — 지금 단계가 강조됨] [활용], 오른쪽 = 브라우저 창(카메라 확대·이동, 영역 강조, 커서·클릭 물결, 입력 효과), 아래 = 자막
- 통합본은 화면 맨 아래에 챕터 바(01~08, 현재 챕터 강조 + 진행 막대)

## 화면 설명 형식

각 기능 장면은 요청한 형식을 따른다: **[기능명] → 한 문장 설명 → 실제 화면 → 사용 방법(단계가 화면 동작과 함께 넘어감) → 활용 목적(왼쪽 아래 "활용" 상자)**.
