# UDJ 실제 기능 (영상 제작용 분석)

- 분석일: 2026-10-02
- 분석 대상: 저장소 `hs-portal/frontend`(React), `hs-portal/backend/app`(FastAPI) + 운영 사이트 https://udjschool.ggm.kr/ 직접 확인
- 원칙: **운영 사이트에서 비로그인 상태로 실제 열리는 기능**만 "핵심 기능"으로 분류했다. 코드에는 있어도 메뉴가 꺼져 있거나 로그인·관리자 전용인 기능은 영상에 넣지 않았다.

## 서비스 정의

**우리동네 직업계고(UDJ, 사이트 표기 "ㅇㅈ")** 는 전국 특성화고·마이스터고 등 **직업계고 정보를 지역·계열·학과 조건으로 찾아보고, 학교별 상세 정보와 진로 적성 테스트를 제공하는 직업계고 정보 포털**이다.

- 학교 기본 정보 출처: 나이스(NEIS) 교육정보 개방 포털 → 학교 계정이 소개·학과·사진·일정 등을 보완
- 수록 학교: **575개교, 17개 시·도** (2026-10-02 `/api/meta` 기준. 계열: 특성화고 489 · 마이스터고 41 · 종합고 45)
- 운영: 특성화고신문 (푸터 표기)
- 주 이용자: 직업계고 진학을 고민하는 **학생·학부모**(회원가입 화면 문구 "학생·학부모가 쓰는 개인 회원가입", 만 14세 미만 보호자 동의 절차 있음 → 중학생 포함), 그리고 정보를 직접 관리하는 **학교**(학교 계정)
- 사이트 메인 문구: "내 꿈에 맞는 직업계고 찾기"

> **'기록해'와의 관계**: 기록해(diary.ggm.kr, 학교생활일지·수업일지·자기소개서)는 **별개 서비스**다. UDJ 쪽에는 푸터 "패밀리 사이트" 링크와 옛 주소(`/journal`)의 이동 안내만 남아 있다. 영상에서 기록해는 전혀 다루지 않았다.

### 사용자 역할 (코드 `ROLE_LABEL`, `App.jsx`)

| 역할 | 가입 방식 | 실제로 할 수 있는 일 |
|---|---|---|
| 비회원 | — | 학교 검색·지도·비교, 학교 상세, 진로 테스트, 학교 일정, 학교 문의 |
| 학생(학생·학부모) | 직접 회원가입(휴대폰 인증, 14세 미만 보호자 동의) | 위 + 즐겨찾기·메모, 즐겨찾기 학교 일정(D-day) |
| 학교 | 학교 계정 신청 → 담당자 확인 전화 → 발급 | 학교 정보·학과·사진·일정 관리, 문의 답변, 조회 통계, 노출 플랜 신청 |
| 선생님 | 학교가 발급 | 선생님 화면(학생 관리 — 상당 부분이 2026-09 기록해로 이동) |
| 관리자 | 내부 | 전체 관리 |

## 핵심 기능 (영상에 사용)

### 1. 홈 — 한눈에 보는 직업계고
- 실제 URL: https://udjschool.ggm.kr/
- 기능: 학교·학과·지역 검색창, 전국 학교 수·지역 수, 가장 많이 찾아본 학교(오늘/이번 달/올해), 계열별 바로가기(특성화고·마이스터고·종합고), 특성화고신문 학교 소식, 진로 테스트 배너
- 사용할 화면: `home_viewport.png`, `home_full.png`
- 영상에서 보여줄 부분: 히어로 → "한눈에 보는 직업계고"(575개교·17개 지역) 강조 → 인기 학교 카드 → 계열별 찾기 강조 → 학교 소식

### 2. 학교 검색 (조건 검색)
- 실제 URL: https://udjschool.ggm.kr/search
- 기능: 학교 이름(줄임말 검색 지원, 예: '안양공고'), 지역(시/도 → 시/군/구 → 구), 학교 계열, **학과 계열**(IT·소프트웨어 등 14개), 남녀공학 필터. 목록 20개씩 페이지, 추천순/이름순
- 사용할 화면: `search_top.png` → `search_typed.png`(이름 "공업" + 지역 "경기") → `search_result_full.png`(결과 7개) / `search_dept_select.png` → `search_dept_full.png`(학과 계열 IT·소프트웨어, 결과 136개)
- 영상에서 보여줄 부분: 필터 4종을 순서대로 강조 → 학교 이름 입력(타이핑) → 검색 클릭 → 결과 목록

### 3. 지도 보기
- 실제 URL: https://udjschool.ggm.kr/search (검색 결과에서 [지도] 전환, Leaflet + OpenStreetMap)
- 기능: 검색 조건 그대로 학교 위치를 지도 핀으로 표시
- 사용할 화면: `search_map.png` (지역 '서울' 72개교)
- 영상에서 보여줄 부분: 지도 전환 → 서울 지역 확대 → 커서 이동

### 4. 학교 상세 정보 + 학교에 문의하기
- 실제 URL: https://udjschool.ggm.kr/schools/{id} (영상 예: `/schools/25` 서울공업고등학교, `/schools/262` 근명고등학교)
- 기능: 기본 정보(남녀공학·기숙사·설립·개교연도), 개설 학과, 위치 및 연락처, 학교 홈페이지, (학교가 등록한 경우) 대표 사진·소개 영상·특성화고신문 기사, **학교에 문의하기**(이메일로 답변 받음), [입학 상담 신청] 버튼(문의 양식으로 이동)
- 사용할 화면: `school_25_full.png`(개설 학과 12개, 대표 사진), `school_262_full.png`(빠른 문의 가능 학교의 문의 양식)
- 영상에서 보여줄 부분: 기본 정보 → 개설 학과 → 위치·연락처 강조 → 문의 양식 강조
- 참고: 서울공업고는 "아직 포털에 계정을 개설하지 않아 답변이 늦을 수 있다"는 안내가 붙어 있어, 문의 장면은 '빠른 문의 가능' 학교(근명고) 화면을 썼다.

### 5. 학교 비교
- 실제 URL: https://udjschool.ggm.kr/search ([비교 담기] → 하단 비교함 → [나란히 비교])
- 기능: 최대 3개교를 계열·지역·주소·남녀공학·기숙사·설립·개교·학생 수·취업률·학과·전화 항목으로 나란히 비교
- 사용할 화면: `search_compare_tray.png`, `search_compare_modal.png`
- 영상에서 보여줄 부분: 비교함 3/3 강조 → [나란히 비교] 클릭 → 비교표 확대

### 6. 취업/진학 정보 ⚠ 가상 데이터 예시로 사용
- 실제 URL: https://udjschool.ggm.kr/schools/{id}/admission
- 기능: 학교가 직접 입력해 공개한 졸업생 진로 통계 — 졸업 후 진로(진학·취업·기타), 대학 진학 유형(4년제·전문대·기타), 진학 권역·계열, 주요 진학 대학·학과, 취업 현황·분야·주요 취업처. 공개 범위는 학교가 선택(전체/로그인/재학생/비공개). 노출 플랜(플래티넘) 혜택이라 **일부 학교에서만** 볼 수 있다.
- 현재 상태: 공개된 학교는 1곳(근명고, id 262)뿐이고, **입력값이 임의(테스트) 데이터**임을 사용자가 확인했다(2026-10-02).
- 영상 처리: 화면 구성만 보여 준다. 캡처 시 학교명을 **"예시고등학교"**로 바꿨고, 장면 내내 **"화면 예시 · 가상 데이터"** 표시를 띄우며, 화면 설명에 "영상 속 수치와 학교명은 가상 데이터 예시" 문구를 넣었다. 나레이션에는 수치를 말하지 않는다.
- 사용할 화면: `admission_full.png`
- 영상에서 보여줄 부분: 상단 지표 카드 → 졸업 후 진로·진학 유형 도넛 차트 강조 → 취업 정보 강조

### 7. 진로 적성 테스트
- 실제 URL: https://udjschool.ggm.kr/quiz
- 기능: 36문항 5점 척도, 6개 관심 축(제작·기계/IT·소프트웨어/디자인·콘텐츠/경영·비즈니스/서비스·보건/농생명·바이오). 위치(주소 검색·현재 위치, 선택)와 통학 거리(10/25/40/55km, 상관없음)를 고르면 통학권 안에서 추천. 결과: 관심 분포, 세부 성향, **추천 학과 TOP 3**, 추천 학교 목록, 이미지로 저장. 로그인 없이 이용 가능.
- 사용할 화면: `quiz_intro_full.png`, `quiz_question.png`(7/36), `quiz_result_full.png`(위치 없이 → 전국 추천)
- 영상에서 보여줄 부분: 시작 화면(통학 거리 옵션) → [위치 없이 테스트 시작하기] 클릭 → 문항 응답 클릭 → 결과(관심 분포 → 추천 학과 TOP 3 → 추천 학교)
- 참고: 결과 화면은 캡처용으로 실제 응답한 결과다(조작 없음).

## 영상에 넣은 기능 선정 (4~7개 기준)

선정 기준: ① UDJ를 대표하는가 ② 학생에게 실제로 쓸모 있는가 ③ 화면으로 보여 주기 쉬운가 ④ 짧게 설명되는가 ⑤ 차별점이 보이는가

| 순서 | 기능 | 90s | 60s | 30s | 15s |
|---|---|:-:|:-:|:-:|:-:|
| 01 | 홈(한눈에 보는 직업계고) | ● | | | |
| 02 | 학교 검색 | ● | ● | ● | ● |
| 03 | 지도 보기 | ● | ● | | |
| 04 | 학교 정보(+문의) | ● | ● | ● | ● |
| 05 | 학교 비교 | ● | ● | | |
| 06 | 취업·진학 정보(가상 데이터 예시) | ● | ● | | |
| 07 | 진로 테스트 | ● | ● | ● | ● |

"가장 좋은", "최고의" 같은 평가 표현은 쓰지 않았다.
