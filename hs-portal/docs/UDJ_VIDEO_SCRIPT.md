## 성우 녹음으로 바꿀 때

1. 위 표의 문장을 그대로 녹음해 `video/src/public/audio/{버전}/{장면}_{번호}.wav` (48kHz, 앞뒤 무음 제거) 로 덮어쓴다
2. `cd video/src && python script/build_audio.py --no-tts` — TTS 를 다시 받지 않고 녹음 파일 길이로 장면 타이밍·SRT 를 다시 계산
3. `python script/build_bgm.py` (길이가 바뀌었으면) → `node render.mjs`
