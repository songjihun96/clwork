# UDJ 소개영상 스토리보드

- 해상도 1920×1080 (16:9), 60fps, H.264 High / AAC 48kHz, 음량 -16 LUFS
- 구성 원칙: **서비스 설명 → 주요 기능 → 활용 → 이용 대상 → 접속 안내**
- 화면 소재: 운영 사이트(https://udjschool.ggm.kr/)를 Playwright 로 실제 캡처한 PNG(2배 해상도). AI 생성 화면 없음.
- 디자인 토큰: 사이트 CSS 그대로 — 배경 `#f8f9fa`/`#fbf6f4`, 브랜드 `#b52701`, 소프트 `#ffdad2`, 텍스트 `#191c1d`·`#5b413a`, 글꼴 Pretendard, 로고 "ㅇㅈ" 검정 마크
- 모션: UI 확대/이동(카메라), 페이드, 슬라이드업, 영역 하이라이트(바깥 살짝 어둡게 + 브랜드색 테두리), 커서 이동·클릭 물결, 타이핑, 카드 순차 등장. 3D·빛 번쩍임·흔들림 없음.

## 공통 화면 배치 (기능 장면)

```
┌──────────────────────────────────────────────────────────────┐
│ [ㅇㅈ] 우리동네 직업계고                                          │
│                                                              │
│  (아이콘) 02          ┌──── 브라우저 창 (실제 URL 표시) ─────────┐ │
│  학교 검색            │                                         │ │
│  조건을 골라 전국…     │    실제 UDJ 캡처 화면                    │ │
│  [지역][학교 계열]…    │    + 확대·이동 / 하이라이트 / 커서        │ │
│  (말하는 항목이 채워짐) │                                         │ │
│                      └─────────────────────────────────────────┘ │
│            ┌──────── 자막(나레이션과 동일) ────────┐               │
└──────────────────────────────────────────────────────────────┘
```
왼쪽 칩(chip)은 나레이션이 그 항목을 말할 때 브랜드색으로 채워진다.
