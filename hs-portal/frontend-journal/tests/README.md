# 화면 검사

브라우저 없이 화면이 실제로 그려지는지 본다.
**빌드가 통과해도 화면에 아무것도 안 뜨는 일**이 여러 번 있어서 만들었다.

## 서버에서는 돌리지 않는다

jsdom 이 Node 22 이상을 요구하는데 서버는 Node 20 이다.
서버에서 돌릴 이유도 없다. 배포에 필요한 것은 `npm run build` 뿐이다.

개발 환경에서 프로젝트 폴더로 들어가 실행한다.

```bash
cd frontend-journal
npm run test:ui
```

## 무엇을 보는가

| 파일 | 보는 것 |
|---|---|
| `page.test.mjs` | **페이지째로** 그려지는지. 버튼을 누르면 안내가 뜨는지 |
| `tour.test.mjs` | 안내의 단계 넘김, 짚을 것이 없을 때의 처리 |

## 왜 페이지째로 보는가

처음에는 `tour.test.mjs` 만 있었다. Tour 부품은 잘 돌았는데,
정작 **화면에 그리는 한 줄이 빠져** 있어 아무 일도 일어나지 않았다.
부품만 시험하면 이런 것을 못 잡는다.

이 검사들이 실제로 잡은 것들
- Tour 를 불러오기만 하고 그리지 않은 것
- `finish` 를 `useEffect` 아래에 선언해 첫 실행에서 터진 것
- 저장이 막힌 브라우저에서 안내가 영영 안 뜬 것
