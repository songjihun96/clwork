# 우리동네 특성화고 (U.D.T)

**U.D.T** — 전국 고등학교를 지역·계열·기숙사 조건으로 찾고, 학교는 노출 플랜을 사서 상단에 올라가는 홍보 포털.
학교 정보는 **나이스(NEIS) 교육정보 개방 포털** 오픈 API에서 실제 데이터를 받아온다.

FastAPI + React(Vite) + SQLite.

---


## 실제 서버에 올리기 (배포)

네이버 클라우드 등 리눅스 서버에 올려 인터넷에 공개하려면
`deploy/DEPLOY_GUIDE_naver_cloud.md` 를 보세요. 준비물:

- `deploy/setup-server.sh` — 서버에서 한 번 실행하면 환경을 세팅
- `deploy/env.example` — 서버용 환경변수 예시 (backend/.env 로 복사해 사용)
- `deploy/udt-backend.service` — 백엔드를 항상 켜두는 systemd 설정
- `deploy/nginx-udt.conf` — 프론트+API를 한 도메인에 묶는 nginx 설정

배포 시 DB는 SQLite에서 **PostgreSQL**로 바뀝니다(`DATABASE_URL` 환경변수).
로컬에서 개발할 때는 지금처럼 아무 설정 없이 SQLite로 돌아갑니다.

## 실행 (Windows)

**`start.bat` 을 더블클릭하면 끝입니다.**

처음 실행하면 순서대로 이렇게 진행됩니다.

1. Python / Node.js 설치 여부 확인
2. 파이썬 가상환경 생성 + 패키지 설치 (1~2분)
3. NEIS 인증키와 관리자 비밀번호를 물어봄 → `backend\.env` 생성
4. 관리자 계정 생성 + 나이스에서 학교 데이터 수집 (몇 분)
5. npm 패키지 설치 (1~2분)
6. 서버 창 두 개가 열리고 브라우저가 자동으로 뜸

두 번째부터는 이미 끝난 단계를 건너뛰고 바로 서버만 켜집니다.

**끄려면** 새로 열린 창 두 개(`포털 - 서버`, `포털 - 화면`)를 닫으면 됩니다.

### 미리 설치해야 하는 것

| 프로그램 | 받는 곳 | 주의 |
|---|---|---|
| Python 3.10+ | https://www.python.org/downloads/ | 설치 화면 맨 아래 **"Add python.exe to PATH" 체크 필수** |
| Node.js LTS | https://nodejs.org | 기본 설정으로 설치 |

둘 중 하나라도 없으면 `start.bat`이 어디서 받는지 알려주고 멈춥니다.

### 배치 파일을 고칠 때 주의

`.bat` 파일에는 **한글을 넣지 마세요.** 한국어 Windows는 배치 파일을 CP949로 읽는데,
파일이 UTF-8로 저장돼 있으면 한글이 깨지면서 명령어까지 망가집니다.
(`chcp 65001`은 파일을 이미 읽은 뒤에 실행되므로 소용이 없습니다.)

한글 안내가 필요하면 파이썬이 출력하게 하세요. `backend\app\setup_env.py`,
`backend\app\update_menu.py` 가 그렇게 하고 있습니다.
줄바꿈도 CRLF를 유지해야 합니다.

### 학교 데이터 다시 받기

`update-schools.bat` 을 실행하면 됩니다.

- 나중에 NEIS 인증키를 발급받았을 때
- 카카오 키를 넣고 지도 좌표를 채울 때
- 학교 정보가 바뀌었을 때 (학교코드로 찾아 갱신하므로 중복되지 않습니다)

### 직접 실행하고 싶다면

```cmd
cd backend
.venv\Scripts\activate
python -m app.import_neis --majors
uvicorn app.main:app --reload

cd frontend
npm run dev
```

| import_neis 옵션 | 설명 |
|---|---|
| `--only 특성화고 마이스터고` | 수집할 계열 지정 (기본: 특성화고·마이스터고·특목고 계열) |
| `--all` | 일반고까지 전부 |
| `--majors` | 학교학과정보 API로 실제 개설 학과까지 수집 (느림) |
| `--geocode` | 카카오 API로 주소 → 좌표 변환 (지도 뷰용) |
| `--if-empty` | 학교가 이미 있으면 아무것도 안 함 (start.bat이 쓰는 옵션) |
| `--office B10 J10` | 특정 교육청만 |

## API 키 관리

키는 전부 `backend\.env` 한 곳에만 있습니다. **코드나 채팅에 직접 붙여넣지 마세요.**

```ini
SECRET_KEY=...          # JWT 서명 키. start.bat이 자동으로 만듭니다
NEIS_API_KEY=...        # 학교 데이터 수집
KAKAO_REST_KEY=...      # 좌표 변환 (지도 뷰를 쓸 때만)
ADMIN_EMAIL=...
ADMIN_PASSWORD=...
```

`.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다. DB 파일(`*.db`)도 마찬가지입니다.
키를 바꾼 뒤에는 서버 창을 닫았다 `start.bat`을 다시 실행하세요.

## 노출 플랜

| 플랜 | 월 요금 | 혜택 |
|---|---|---|
| 무료 | 0원 | 검색 노출, 기본 정보 등록 |
| 베이직 | 99,000원 | 일반 학교보다 상단, 입시 일정 등록, 조회수 통계 |
| 프리미엄 | 249,000원 | 상위 고정, 대표 이미지, 일자별 통계 |
| 플래티넘 | 499,000원 | 최상단 고정, 추천 배지, 즐겨찾기 분석 |

**결제는 관리자 수동 승인 방식이다.** 학교가 신청 → 관리자가 입금 확인 후 승인 → 그 시점부터 기간 시작.
남은 기간이 있으면 이어붙는다. 만료일이 지나면 자동으로 무료로 내려간다.

검색 기본 정렬은 `플랜 등급 → 평점 → 이름` 순이다.

## NEIS에서 받아오는 값과 아닌 값

| 항목 | 출처 |
|---|---|
| 학교명, 지역, 주소, 전화, 홈페이지, 남녀공학, 계열, 설립구분, 개교연도 | NEIS 학교기본정보 |
| 개설 학과 | NEIS 학교학과정보 (`--majors`) |
| 좌표 | 카카오 지오코딩 (`--geocode`) |
| **기숙사 여부** | **NEIS에 없음** — 학교 계정이 직접 입력. 그전까지는 "미확인" |
| 소개, 실습시설, 취업률, 학생수, 입시일정 | 학교 계정이 직접 입력 |

기숙사 필터에 "미확인" 선택지를 따로 둔 이유가 이것이다. 없는 값을 추측해서 채우지 않았다.

## 계열 분류 방식

NEIS의 `HS_SC_NM`(일반고/특성화고/마이스터고/특목고)과 `SPCLY_PURPS_HS_ORD_NM`(특목고 계열명)을 합쳐 하나로 정리한다.

- `특목고` + `과학계열` → **과학고**
- `마이스터고` + `산업수요맞춤형고` → **마이스터고**
- `특성화고` → **특성화고**

검색 드롭다운은 하드코딩이 아니라 **DB에 실제로 있는 값**에서 만든다. 수집 범위를 바꾸면 드롭다운도 따라 바뀐다.

## 데이터 초기화

`reset-data.bat` 을 실행하면 무엇을 지울지 골라서 초기화할 수 있다.

1. **플랜만 초기화** — 모든 학교를 무료 플랜으로 되돌리고 플랜신청 내역 삭제. 학교 정보·좌표·계정·후기는 유지.
2. **계정·후기 지우기** — 학생/학교 계정, 후기, 즐겨찾기, 플랜신청 삭제. **학교 정보와 좌표, 관리자 계정은 유지.**
3. **학교까지 함께 지우기** — 위 + 학교 전체 삭제. 관리자만 남는다. 다시 채우려면 `update-schools.bat` 실행.
4. **완전 초기화** — DB 파일을 통째로 삭제. `start.bat` 재실행 때 처음부터 새로 만든다.

각 단계마다 현재 데이터 개수를 보여주고 y/n 확인을 받는다. 실수로 지우지 않도록 취소(0)도 있다.

## 모바일(폰)에서 테스트하기

PC와 폰을 **같은 Wi-Fi**에 연결한 뒤 `start-mobile.bat`을 실행하세요.

1. `start-mobile.bat` 더블클릭 → 검은 창에 접속 주소가 뜬다 (예: `http://192.168.0.10:5173`)
2. 폰 브라우저 주소창에 그 주소를 입력
3. 처음 실행하면 **Windows 방화벽 허용** 창이 뜬다 → Python과 Node.js 둘 다 "액세스 허용"(개인 네트워크)을 눌러야 폰에서 접속된다

`start.bat`으로 먼저 설치를 끝낸 뒤에 써야 한다(가상환경·DB가 있어야 함).

**안 될 때:**
- PC와 폰이 같은 Wi-Fi인지 확인(게스트 Wi-Fi는 기기 간 차단이 많음)
- 방화벽 허용을 놓쳤다면: 제어판 → Windows Defender 방화벽 → 앱 허용에서 Python/Node 확인
- 회사·학교 네트워크는 기기 간 통신을 막는 경우가 있음 → 폰 핫스팟에 PC를 연결해 테스트

## 진로 적성 테스트

36문항 5점 척도(전혀 그렇지 않다~매우 그렇다)로 관심 분야를 파악하고,
**사는 시·도와 통학 시간**을 받아 통학 가능한 범위 안에서 추천 학과와 학교를 골라준다.

- 6개 관심 축(제작·기계 / IT / 디자인 / 경영 / 서비스·보건 / 농생명) × 6문항 = 36문항으로 채점
  - 축당 역문항 2개를 섞어 한쪽으로만 답하는 응답을 줄인다(`quiz_bank.py`)
  - 문항이 늘어난 만큼, 모든 문항에 같은 번호만 고르거나 응답 편차가 거의 없으면
    결과 화면에 신뢰도 경고를 띄운다(`quiz.py: response_quality`)
  - 1위·2위 축 점수 차이가 10점 미만이면 "비슷하게 어울리는 분야"로 안내한다(`score_confidence`)
- 상위 축에 맞는 학과 계열 TOP 3을 추천하고, 그 학과를 실제로 개설한 학교를 찾음
- **위치 입력**: 도로명주소 검색(카카오 API) 또는 현재 위치(브라우저 GPS). 선택 사항이다.
- **통학 거리**: 사용자 실제 좌표 ↔ 학교 실제 좌표 직선거리(하버사인)만 쓴다. 좌표가 없는 학교는 거리 계산에서 빠진다(억지로 0km로 만들지 않는다).
- 통학 시간은 대중교통 기준 대략 환산(1시간 ≈ 25km)
- 위치를 안 넣으면 전국 대상으로 학과만 매칭해 플랜 순으로 추천
- 결과 카드를 PNG 이미지로 저장(html2canvas)

**주소 검색은 카카오 REST 키가 필요하다.** `.env`에 `KAKAO_REST_KEY`가 없으면 주소 입력란이 비활성화되고 현재 위치(GPS)만 쓸 수 있다. GPS는 키 없이 바로 된다.

학교 좌표를 채우려면 `update-schools.bat` → 3번(카카오 좌표 변환)을 돌려야 통학권 추천이 나온다.

## 검증된 동작

- 플랜 등급이 평점을 이긴다 (프리미엄·평점 0 → 무료·평점 5.0보다 위)
- 만료일 지난 유료 플랜은 조회 시점에 무료로 강등
- 학생이 학교 계정 생성 API 호출 시 403
- 무료 플랜은 입시 일정 등록 차단
- 같은 학교에 후기 중복 작성 불가 (UNIQUE 제약)
- 학교 본인·관리자가 상세를 봐도 조회수가 오르지 않음
- NEIS 재수집 시 학교코드 기준으로 갱신, 중복 생성 없음
- `.env`가 이미 있으면 `start.bat` 재실행 시 덮어쓰지 않음
- 8자 미만 관리자 비밀번호는 거절
- 검색 결과 페이지당 20개 (47개 → 20/20/7로 나뉨), `size` 상한 100
- 모든 배치 파일이 순수 ASCII + CRLF
- 모바일 반응형(헤더 가로스크롤, 카드 세로배치, 모달 바텀시트)
- 밝고 따뜻한 디자인 톤(산호·오렌지, 둥근 카드, 넉넉한 여백)
- 검색 필터에서 기숙사 제거(카드 표시는 유지)
- 진로 테스트: 위치 있으면 실제 거리로 통학권 필터, 없으면 전국·거리 미표시
- 진로 테스트 '거리 상관없음' 선택 시 결과에서 거리 숨김
- reset-data.bat: 플랜만/계정·후기/학교포함/완전 4단계 초기화
- 관리자 웹: 학교별 상세정보 초기화(기본정보·플랜 유지), 플랜 초기화(정보 유지) 각각
- 학교 수집이 실패해도 사이트는 정상적으로 열림
