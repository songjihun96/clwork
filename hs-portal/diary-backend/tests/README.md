# 검사

AI 기능을 붙이며 만든 검사들. 배포 전에 돌려 본다.

```bash
cd /root/hs-portal/diary-backend
for f in tests/*.py; do
  echo "── $f"
  .venv/bin/python "$f"
done
```

## 무엇을 보는가

| 파일 | 보는 것 |
|---|---|
| `regress.py` | **기존 기능이 안 깨졌는가.** 일지·자소서·문서·관리자 |
| `aitest.py` | **AI 가 없는 사실을 만들지 않는가.** 지시서 10종 |
| `priv.py` | **개인정보가 밖으로 안 나가는가.** 방침 제7조 약속 |
| `llm.py` | **AI 가 죽어도 서비스가 사는가** |
| `jobs.py` | 작업 큐. 일꾼이 안 죽고 같은 일을 두 번 안 하는가 |
| `svc.py` | 가리기→부르기→되돌리기 흐름 |
| `apiai.py` | API. 동의 없이 안 나가는가, 캐시가 도는가 |
| `flow4.py` | 학생이 실제로 겪는 순서대로 |
| `journal_resume.py` | 일지 카테고리·직업군·"이 항목에 쓸 만한 내 기록" 순서·지원동기 질문(1~2학년 기록만) |
| `seat_code_school.py` | 학교가 정해지지 않은 학생의 이용권 코드 등록 |
| `personal_purchase.py` | 일지 종류 필터·항목별 직접 고른 기록·개인 구매(카드/무통장/환불)·학년 자동 계산 |
| `free_trial.py` | 첫 달 무료: 달력 1개월 계산·무료 중 자소서 열림·종료 후 402·유료 전환(테스트 결제 제외)·관리자 지표/기간 관리 |
| `notices.py` | 기록해 공지사항(UDJ 와 별개): 게시·임시저장·중요 공지, 학교 계정에만 알림 메일, 학교급 대상, 중복 방지·재발송, 이벤트는 발송 안 함 |

## 주의

`aitest.py` 는 AI 응답을 흉내 낸다. **실제 AI 품질을 재지 않는다.**
"AI 가 이상한 답을 줬을 때 우리 코드가 막는가" 를 본다.

실제 품질은 키를 넣고 진짜 일지로 확인해야 한다.
